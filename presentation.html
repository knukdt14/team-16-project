🚨 ISSUE 01. 수치 데이터 쉼표(,) 포맷으로 인한 500 Server Error
01 / 04
🚨 현상 (Symptom)
지도의 특정 시도(전북, 충남, 충북, 경북 등) 클릭 시 상세 보조금 데이터가 렌더링되지 않고 '데이터 없음'으로 표시되는 반면, 보조금이 1,000만원 미만인 지역(경남 등)은 정상 출력됨.
1번 사진: 경남 (977만원 - 1000만 미만 정상)
2번 사진: 경북 (1000만 이상 '데이터 없음' 에러)
🔍 원인 예시 (3번 사진)
보조금 1,000만원 이상 데이터에 1,028과 같이 천 단위 쉼표(,)가 포함되어 백엔드 int() 변환 시 ValueError 발생.
🛠️ 해결 예시 (4번 사진)
데이터 전처리 스크립트를 작성하여 수치 컬럼 내 쉼표(,)를 일괄 제거해 1028 정수형으로 즉시 파싱 가능하도록 최적화.
💡 성과 (Result)
데이터 파싱 예외 완전 방어 및 전국 17개 지자체 보조금 지도 상세 렌더링 100% 정상 구동 달성.
🧠 ISSUE 02. AI 챗봇 대화 세션 맥락(Context) 유실 및 지역 무한 되묻기
02 / 04
🚨 현상 (Symptom)
지도 선택("경남") 후 차종("코나") 또는 트림("코나 롱레인지")을 대답해도, 이전 지역 정보를 기억하지 못하고 "거주하시는 지역을 알려주세요"라며 지역을 계속 다시 되묻는 무한 되묻기 루프 현상 발생.
🔍 원인 (Root Cause)
단발성 API 호출 구조로 인해 대화 엔티티(지역, 차종)가 세션 단위로 보존되지 않고 새 메시지 전송 시 null로 초기화되어 백엔드로 전달됨.
🔄 대화 맥락 유실 - 무한 되묻기 루프 대화 예시 (1 ➔ 2 ➔ 3단계 흐름)
1단계: 지도 지역("경남") 선택 후 차종("코나") 대답
↓
2단계: 경남 유실 -> 거주 지역 다시 물음 -> 트림 대답
↓
3단계: 또다시 경남 유실 -> "거주하시는 지역을 알려주세요" 무한 되묻기 루프 갇힘
🛠️ 해결 방안 및 성과 (Solution & Result)
  • 프론트엔드(Chatbot.jsx) 내 useRef 기반 대화 맥락 객체(ctx.current = { region, model }) 구축.
  • 지도 클릭 및 되묻기 옵션 선택 시 이전 지역/차종을 메모리에 누적 보존하여 백엔드 전송 시 함께 누적 전달하도록 상태 관리 개편.
  • 이전 대화 맥락을 완벽히 기억하는 자연스러운 멀티턴(Multi-turn) 대화 흐름 및 사용자 경험(UX) 완성.
📝 ISSUE 03. 챗봇 답변 텍스트 개행(\n) 및 파서 렌더링 미반영 결함
03 / 04
🚨 현상 (Symptom)
LLM 및 백엔드에서 개행 문자(\n) 및 **강조** 마크업을 포함하여 응답을 반환해도 챗봇 대화창에서 줄바꿈이 무시되고 텍스트가 한 줄로 빽빽하게 렌더링됨.
🔍 원인 (Root Cause)
React 기본 JSX 렌더링 시 \n 문자가 일반 공백 처리되며, 기존 커스텀 텍스트 파서(Bold 파서) 내에 줄바꿈 요소(<br />) 변환 처리 미비.
🖼️ 렌더링 비교 예시 (Before vs After)
❌ 수정 전 (1번 사진: 줄바꿈 미반영)
✅ 수정 후 (2번 사진: 줄바꿈 반영)
🛠️ 해결 방안 및 성과 (Solution & Result)
  • renderAnswer 파싱 도우미 함수 설계: 텍스트를 \n 단위로 split 후 개행(<br />) 노드로 전환.
  • 기존 **강조(Bold)** 마크업 파서 정규식과 통합하여 단락과 강조 텍스트가 동시에 정상 적용되도록 고도화.
  • 규정/근거 등 복잡하고 긴 답변 텍스트의 가독성 및 UI 문단 구획 완성도 극대화.
✨ SUMMARY. 트러블슈팅 총평 및 핵심 성과
04 / 04
1. 데이터 파이프라인 무결성 확보 (Data Integrity)
공공데이터의 예외적 수치 포맷(천 단위 쉼표 등)을 사전 전처리하여 백엔드 파싱 예외 500 에러를 100% 방어함.
2. 지능형 멀티턴 상태 관리 (State Management)
useRef 기반의 세션 맥락 보존 객체를 설계하여 단발성 LLM 호출의 한계를 극복하고 자연스러운 대화 유도.
3. 프론트엔드 파싱 및 UI/UX 세심화 (Text Parsing & UX)
강조 마크업과 개행 처리가 동시에 동작하는 커스텀 파서를 통해 사용자에게 가독성 높은 챗봇 인터페이스 전달.
